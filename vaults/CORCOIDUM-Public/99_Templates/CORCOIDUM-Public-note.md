## 검토 체크

- [ ] 실제 환자·보호자·직원 식별 정보가 없다.
- [ ] 희귀한 사건 조합으로 재식별될 가능성이 없다.
- [ ] API key, token, 내부 URL, 계정 정보가 없다.
- [ ] 공개용 문서로 독립 작성했다.
- [ ] 제목, 태그, 본문, 링크, frontmatter를 확인했다.
- [ ] 관계 대상이 승인된 Public 노트인지 확인했다.
